# Prompts para crear libros infantiles para colorear

Genera y revisa cada ilustración por separado. Los prompts son una base reutilizable: sustituye los campos entre corchetes según el brief del libro.

## Prompt maestro para una ilustración interior

> Crea una única ilustración original para una página de libro infantil para colorear sobre **[TEMA/ESCENA]**, dirigida a niños de **[EDAD]** años. Formato vertical A4, composición centrada, fondo blanco puro. Dibujo lineal en blanco y negro: contornos negros gruesos, limpios, continuos y bien cerrados; formas grandes y sencillas; espacios amplios para colorear; expresión amable; pocos elementos secundarios. El sujeto completo debe quedar dentro de márgenes seguros. Estilo infantil coherente, claro y fácil de imprimir. No incluyas texto, letras, números, bordes decorativos, marcas de agua, logotipos, grises, sombras, degradados, texturas, tramas, color ni fondos complejos. Una sola escena por imagen.

## Prompt para mantener una colección consistente

> Crea una ilustración que pertenezca a la colección **[TÍTULO]**. Mantén exactamente el mismo lenguaje visual, grosor de contorno, proporciones, nivel de detalle y tipo de composición de las demás páginas de la colección. Tema de esta página: **[ESCENA]**. Debe ser una página individual vertical A4, fondo blanco puro, contornos negros gruesos y áreas grandes para colorear. No incluyas texto, números, sombras, grises, color, marcas de agua ni elementos cortados.

Genera cada escena como archivo independiente. No pidas una cuadrícula o collage cuando el destino sea un PDF paginado.

## Prompt para portada a color

> Diseña una portada frontal infantil para un libro titulado **[TÍTULO]**, sobre **[TEMA]**, para niños de **[EDAD]** años. Ilustración original, alegre y amable, paleta pastel suave, título grande y perfectamente legible, jerarquía clara, orientación vertical A4, márgenes seguros y composición equilibrada. No uses personajes, marcas ni logotipos de terceros. No añadas texto pequeño ilegible ni marcas de agua.

## Prompt para página de bienvenida

> Diseña una página editorial de bienvenida para **[TÍTULO]**. Idioma: **[IDIOMA]**. Usa exactamente este texto revisado: **[TEXTO]**. Diseño limpio, infantil y fácil de leer, márgenes seguros, orientación vertical A4. No inventes palabras ni cambies la ortografía del texto suministrado.

## Prompt para contraportada

> Diseña una contraportada para **[TÍTULO]**, en coherencia con la portada, con paleta pastel suave y composición sencilla. Incluye únicamente este texto, si se solicita: **[TEXTO]**. Mantén márgenes seguros y no inventes logotipos, códigos, precios ni marcas de agua.

## Ajustes por edad

- **2-4 años:** figuras muy grandes, contornos extra gruesos y 1-3 elementos principales.
- **3-6 años:** escenas simples, 2-5 elementos y detalles amplios.
- **6-8 años:** algo más de detalle, manteniendo áreas generosas para colorear.

## Control de calidad de cada imagen

- [ ] Una sola escena, no collage.
- [ ] Fondo blanco puro y contornos negros.
- [ ] Sin grises, sombras, degradados ni texturas.
- [ ] Formas cerradas y áreas amplias para colorear.
- [ ] Nada importante queda cortado.
- [ ] Sin letras, números, marcas de agua ni logotipos.
- [ ] Nivel de dificultad adecuado a la edad.
- [ ] No copia personajes ni obras protegidas.
- [ ] Se mantiene coherencia con las demás páginas.
