# Prompts para crear páginas de colorear

Genera una imagen por página y revisa cada resultado antes de incluirlo en un libro.

## Prompt maestro
> Crea una página infantil para un libro de colorear sobre **[TEMA]**, dirigida a niños de **[EDAD]** años. Ilustración en blanco y negro puro, solo contornos negros limpios y gruesos sobre fondo blanco. Formas grandes, sencillas y cerradas, pocos detalles, composición centrada, expresión amable, sin elementos cortados por los bordes. Estilo educativo para preescolar, apto para imprimir en papel A4 vertical. No incluyas texto, letras, números, marcas de agua, grises, sombras, degradados, tramas ni color. Una sola escena, sin marco decorativo.

## Ajustes por edad
- **2-4 años:** figuras muy grandes, contornos extra gruesos, máximo 3 elementos principales.
- **4-6 años:** escena simple con 3-5 elementos y detalles amplios.
- **6-8 años:** algo más de detalle, manteniendo espacios amplios para colorear.

## Colección coherente
> Diseña una serie de 20 páginas independientes sobre **[TEMA]**. Mantén el mismo grosor de línea, nivel de detalle, proporciones y estilo. Cada página debe contener una escena distinta. Entrega cada ilustración como imagen individual, blanco y negro, fondo blanco, formato vertical A4, lista para impresión.

## Portada
> Crea una portada infantil alegre para un libro titulado **[TÍTULO]**, con ilustraciones originales sobre **[TEMA]**, composición limpia, paleta pastel suave, título grande y legible, orientación vertical A4, sin logotipos ni marcas de agua. Deja márgenes seguros.

## Control de calidad
1. Fondo blanco, sin grises ni sombras.
2. Formas y contornos legibles, sin deformaciones.
3. Sin texto ilegible ni marcas de agua.
4. Composición centrada y no cortada.
5. Ilustración original, sin copiar personajes protegidos.
