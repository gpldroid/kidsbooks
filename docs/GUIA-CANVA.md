# Guía de Canva para maquetar libros

## 1. Preparar el documento

1. Crea un diseño personalizado en Canva: A4 (210 × 297 mm), orientación vertical, salvo que el brief aprobado indique otro tamaño.
2. Usa el mismo tamaño y orientación en todas las páginas, incluidas portada y contraportada.
3. Define el orden y el número de páginas antes de empezar.
4. Deja márgenes seguros de 12-15 mm como mínimo; amplíalos si el encuadernado lo requiere.
5. Nombra las páginas o usa una hoja de control externa para evitar errores de secuencia.

## 2. Interior de colorear

- Fondo blanco puro.
- Una ilustración por página.
- Ilustración centrada y a escala consistente.
- Contornos negros nítidos y suficientemente gruesos.
- Sin fondos de color, sombras, grises, tramas ni elementos que gasten tinta.
- No coloques elementos importantes junto al borde.
- Comprueba que las líneas se impriman con claridad.

## 3. Páginas blancas protectoras

Cuando el brief solicite una página en blanco detrás de cada ilustración:

1. Inserta una página nueva inmediatamente después de cada ilustración.
2. Esa página debe estar completamente vacía: sin texto, número, logotipo, fondo, marco, elemento oculto ni marca.
3. No uses una página blanca como sustituto de una ilustración faltante.
4. Comprueba que la cantidad y las posiciones de estas páginas coincidan con el plan.
5. Verifica el PDF exportado; no confíes únicamente en la vista del editor.

## 4. Portada y páginas editoriales

- La portada puede usar ilustración a color y paleta pastel.
- Revisa título, ortografía, edad y legibilidad en miniatura.
- Si hay página de bienvenida, usa el texto aprobado en el idioma indicado.
- Mantén títulos y elementos importantes dentro del área segura.
- Añade contraportada según el brief.

## 5. Exportar PDF

1. Selecciona PDF para impresión cuando esté disponible.
2. Usa el tamaño de página definido en el brief.
3. Evita marcas de corte y sangrado si no forman parte de las especificaciones de impresión.
4. Descarga el archivo y ábrelo fuera de Canva.
5. Comprueba el total de páginas, tamaño, orientación y secuencia.
6. Revisa todas las páginas en miniatura y a tamaño de lectura.
7. Comprueba que las páginas blancas protectoras estén realmente vacías.
8. Comprueba que el archivo no esté protegido con contraseña y que se pueda imprimir.

## 6. Checklist antes de entregar

- [ ] Número total de páginas coincide con el brief.
- [ ] Portada y contraportada correctas.
- [ ] Bienvenida y textos sin errores.
- [ ] Todas las ilustraciones son distintas, completas y legibles.
- [ ] Páginas blancas protectoras en las posiciones previstas.
- [ ] Todas las páginas tienen el tamaño y orientación correctos.
- [ ] PDF abre y se puede imprimir.
- [ ] El archivo editable de Canva y el PDF final están guardados.
- [ ] Derechos de uso y distribución comprobados.
