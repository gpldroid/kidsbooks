# Guía de Canva para maquetar libros

## Documento
1. Crea un diseño personalizado en Canva: A4 (210 × 297 mm) o US Letter (8.5 × 11 pulgadas).
2. Usa el mismo tamaño y orientación en todas las páginas.
3. Deja un margen interior mínimo de 12-15 mm.
4. Coloca una ilustración por página.

## Interior
- Fondo blanco puro.
- Ilustración centrada y a escala consistente.
- Evita fondos de color y elementos que gasten tinta.
- No coloques elementos importantes junto al borde.
- Comprueba que las líneas se impriman con claridad.

## Portada
- Incluye título, tema y rango de edad.
- Usa ilustraciones originales y paleta pastel.
- Comprueba la legibilidad en miniatura.
- Mantén textos y elementos importantes dentro del área segura.

## Exportar PDF
1. Selecciona PDF para impresión cuando esté disponible.
2. Descarga y abre el PDF exportado.
3. Revisa todas las páginas, orden, tamaño y orientación.
4. Comprueba que no existan páginas vacías accidentales.
5. Comprueba que el archivo no esté protegido con contraseña.

## Checklist
- [ ] Portada correcta y sin errores.
- [ ] Todas las páginas son distintas y completas.
- [ ] Fondo blanco y líneas negras visibles.
- [ ] PDF abre correctamente.
- [ ] Tienes derechos para usar todos los elementos.
